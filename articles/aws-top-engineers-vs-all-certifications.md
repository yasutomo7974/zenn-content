おはようございます、YASUです。

AWSには、日本のエンジニアを対象にした表彰プログラムとして、「Japan AWS Top Engineers」と「Japan All AWS Certifications Engineers」があります。名前だけは聞いたことがありましたが、条件をきちんと見たことがなかったので、AWS Japanが公開している2026年版のクライテリアを読んで、整理しました。私もいずれ目指したいと考えています。

## 結論

どちらも、AWS Japanが、AWSパートナーネットワーク(APN)に参加している会社に所属するエンジニアを表彰するプログラムです。All AWS Certifications Engineersは「AWS認定資格をすべて持っていること」が条件で、Top Engineersは、資格に加えて、AWSのビジネス拡大につながる技術的な活動も審査されます。

## どちらにも共通する条件

- 所属する会社の条件:APNに参加している会社に所属していること。カテゴリーに応じて、サービスパスまたはトレーニングパスのAWSセレクトティア以上、もしくは、ソフトウェアパスのConfirmedステージ以上が求められる
- 認定資格の有効期限:申し込み時点で有効で、審査期間の終わり(2026年版は4月30日)まで有効であること
- 証明:AWS認定資格を持っている証拠として、デジタルバッジが必要。申し込み前に、シェアの設定をしておく

つまり、どちらも、個人で応募するのではなく、所属している会社のパートナーとしての条件が、前提になります。

## Japan All AWS Certifications Engineers

対象のAWS認定資格を、すべて保持しているエンジニアを表彰するプログラムです。2026年版の対象は、次の12種類です。

- Cloud Practitioner
- AI Practitioner
- Solutions Architect - Associate
- SysOps Administrator - Associate、またはCloudOps Engineer - Associateのいずれか
- Developer - Associate
- Data Engineer - Associate
- Machine Learning Engineer - Associate
- Solutions Architect - Professional
- DevOps Engineer - Professional
- Security - Specialty
- Machine Learning - Specialty、またはGenerative AI Developer - Professionalのいずれか
- Advanced Networking - Specialty

Machine Learning - Specialtyは、2026年3月31日で受験が終了する予定とされ、Generative AI Developer - Professionalの取得でも、条件を満たすと案内されています。2026年の選出者は、2,330名でした。受賞者には、AWSパートナー向けのテクニカルセッションの優先参加権と、副賞が提供されます。

## Japan AWS Top Engineers

特定のAWS認定資格を持ち、AWSのビジネス拡大につながる技術力を発揮した活動を行っているエンジニアを、AWS Japanが審査して選出するプログラムです。表彰カテゴリーは、3つあります。

- Services:AWSに関する活動を、総合的に判断して表彰する。資格条件は、Solutions Architect - Professionalを保持し、DevOps Engineer - ProfessionalまたはGenerative AI Developer - Professionalのどちらか1つを保持していること
- Software:自社プロダクトの開発で、高度なAWS技術を使って活躍しているエンジニアが対象。資格は、ポイント制で、Associateが1ポイント、Specialtyが1ポイント、Professionalが2ポイントとして、合計2ポイント以上
- Networking、Security、AI/ML Data Engineer:専門領域で、高度な技術を持つエンジニアが対象。Specialtyなどの資格が条件

資格のほかに、活動の実績も必要です。2026年版では、2025年4月1日から2026年3月31日までの活動が、対象でした。

- 活動は、5つのカテゴリー(パブリックコントリビューション、技術リードとしての活動、案件対応、ISV自社製品やソリューションの開発、その他の技術的な活動)に分けられ、1つ以上のカテゴリーで、実績を示す必要がある
- 各カテゴリーの活動は、3つまで、1つあたり400文字まで記述する
- 各カテゴリーで、少なくとも1つは、Level 300以上の内容を含める
- パブリックコントリビューション(ブログ、登壇など)は、誰でもアクセスできる公開URLが必須で、自分の名前が分かるものを指定する

2026年の選出者は、Servicesカテゴリーだけで182名でした。受賞者には、Top Engineers向けのイベントへの招待、パートナー向けトレーニングの先行案内、グッズ、AWSのブログでの公表などの特典があります。

## 2つを比べると

- All AWS Certifications Engineers:資格をすべて取れば、対象になる。資格の数と幅が問われる
- AWS Top Engineers:資格に加えて、技術的な活動の実績が審査される。資格の「深さ」と、活動の成果が問われる

## スケジュールの流れ(2026年版の場合)

- 2025年11月〜12月:クライテリアの発表
- 2026年2月末〜3月末:応募期間
- 2026年4月〜5月:審査
- 2026年6月:受賞者の発表

ただし、条件は毎年変わります。例えば、2026年版では、ServicesとAI/ML Data Engineerの資格条件が、前年から変更されました。目指す場合は、その年の最新のクライテリアを、AWS Japan APNブログで確認する必要があります。

## まとめ

- Japan All AWS Certifications Engineersは、対象の12種類の認定資格をすべて持つエンジニアの表彰
- Japan AWS Top Engineersは、資格に加えて、AWSのビジネスに貢献する技術的な活動が審査される
- どちらも、APNに参加している会社に所属していることが、前提の条件
- 認定資格は、申し込み時点と審査期間の終わりまで有効である必要がある
- 条件は、毎年変わるので、最新のクライテリアを確認する

資格の数だけでなく、活動の実績も見られるTop Engineersは、日々の学習や発信の積み重ねが、そのまま評価につながる仕組みだと分かりました。それでは、また明日!
